# 青青子衿

单网址浏览器安卓平板 APP，专为访问 `https://music.gdstudio.org/` 设计。

## 功能

- 单网址限制：只允许访问 music.gdstudio.org，其他网址自动拦截
- 全屏沉浸式：隐藏状态栏和导航栏
- 音乐优化：启用 JS、DOM 存储、媒体自动播放
- 返回键导航：按返回键在网页内后退，不会直接退出
- 加载进度条：顶部显示页面加载进度
- 横竖屏自适应：支持平板横屏和竖屏

## 构建方式

通过 GitHub Actions 云端构建，无需本地开发环境。

1. 推送代码到 GitHub main 分支
2. 自动触发 Actions 构建
3. 在 Actions 页面下载 APK
